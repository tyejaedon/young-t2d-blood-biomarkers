# Notebook Workflow

This project is developed primarily in Jupyter notebooks. Use the numbered notebooks in order:

1. `00_project_setup.ipynb`
2. `01_data_inventory.ipynb`
3. `02_qc_preprocessing.ipynb`
4. `03_differential_expression.ipynb`
5. `04_pathway_enrichment.ipynb`
6. `05_biomarker_modeling.ipynb`

Each notebook is a starter scaffold with reproducibility settings, project paths, and placeholders for the analysis workflow.
